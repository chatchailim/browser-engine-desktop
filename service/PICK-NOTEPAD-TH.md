# หน้าทดสอบแบบเลือก Notepad โดยตรง

เปิด `OPEN-LIVE-TEST.cmd` รุ่นใหม่ ชื่อหน้าต่าง **Browser Engine - PICK NOTEPAD**

1. เปิดเอกสาร Notepad ใหม่ที่ใช้ทดสอบ ไม่ใช้ไฟล์เพลง
2. พิมพ์ ENABLE ในคอนโซลแล้ว Enter อยู่ที่คอนโซลต่อ ไม่ต้องสลับหน้าต่างตอนนี้
3. ระบบแสดงเฉพาะหน้าต่างของ executable ที่อนุญาต พิมพ์หมายเลขบรรทัดที่ชื่อ Untitled - Notepad แล้ว Enter ห้ามเลือกเอกสารงานจริง
4. เมื่อขึ้น action> พิมพ์ TEST แล้ว Enter ระบบจะแสดงคำสั่งพิมพ์ข้อความ ` TEST-456` ให้ตรวจ
5. พิมพ์รหัสอนุมัติที่แสดงแล้ว Enter จากนั้นคลิกช่องพิมพ์ใน Notepad ที่เลือกและปล่อยเมาส์ ระบบจะรอจนหน้าต่างนี้พร้อม ก่อนตรวจ guard ทุกข้อแล้วส่งอินพุต

ไม่มีเวลานับถอยหลังตอนเลือกหน้าต่าง การรอโฟกัสหลังอนุมัติไม่เกิน 20 วินาทีและไม่เกินอายุอนุมัติเดิม 30 วินาที ไม่มีการต่ออายุสิทธิ์เอง หากหมดเวลา/หยุด/เป้าหมายเปลี่ยนจะไม่ส่งคำสั่งใหม่และไม่ retry

TEST เป็นเพียงทางลัดแทน JSON ยังต้องผ่าน approval และ guard เดิม ไม่เปลี่ยนสิทธิ์ระบบ ไม่ควบคุม terminal แทนผู้ใช้ บันทึก input_submitted ยังต้องตรวจภาพ Notepad จริงก่อนถือว่าพิมพ์สำเร็จ
