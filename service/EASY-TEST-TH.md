# ทดสอบแบบปุ่มใหญ่สำหรับผู้ใช้

สถานะล่าสุด: Codex ทดสอบจริงผ่านการพิมพ์/อ่านข้อความกลับ/ยกเลิกก่อนส่ง/เริ่มใหม่หลังยกเลิกแล้ว ดู coordination/codex-anti/codex-output/DESKTOP-INPUT/FIX-COMPLETE-TH.md ไม่ใช่การรับรอง click/drag ทุกแอป

เปิดได้ด้วย EasyTest.exe โดยตรง ใช้ F5 ค้นหา, F6 อนุมัติคำสั่งที่แสดง, Escape ยกเลิกได้ด้วย ตัวทดสอบตรวจข้อความกลับเองและขึ้นข้อความผ่านเมื่อค่าอ่านกลับตรง ไม่ต้องส่งภาพเพื่อยืนยันขั้นพิมพ์อีกต่อไป

เปิด `easy_desktop_test.py` ด้วย Python ของโครงการ หน้าต่างชื่อ **ทดสอบพิมพ์ — ปุ่มใหญ่** ใช้ตัวอักษร Tahoma 20–26 และปุ่มขนาดใหญ่ ไม่ต้องพิมพ์ ENABLE, TEST, JSON หรือรหัสสุ่ม

1. กด **1. ค้นหา Notepad ทดสอบ** ระบบเสนอเฉพาะเอกสาร Untitled ไม่แสดงไฟล์เพลง
2. กด **2. อนุมัติให้พิมพ์ TEST-456** เมื่อพร้อม การกดนี้เป็นการอนุมัติเฉพาะคำสั่งที่แสดง
3. คลิกช่องข้อความใน Notepad ที่เลือก แล้วปล่อยเมาส์ ภายใน 30 วินาที

ตรวจว่าข้อความปรากฏจริงและส่งภาพให้ Codex รับรอง กด **หยุด / ยกเลิก** ได้ระหว่างรอ หากผิดพลาดหน้าต่างจะแสดงสาเหตุและบันทึกใน data/desktop-input/easy-*.jsonl

การอนุมัติยังใช้ token ครั้งเดียวภายในโปรแกรม แต่ไม่ให้ผู้ใช้คัดลอกหรือเห็น token อายุสิทธิ์เริ่มเมื่อกดปุ่มอนุมัติ ไม่เริ่มตอนกำลังอ่านคำแนะนำ การเปิด GUI ไม่เปิด native backend จนกดปุ่มค้นหา การค้นหาอ่านข้อมูลเท่านั้น ส่วน input ต้องกดปุ่มอนุมัติต่างหาก

ยังตรวจ identity, allowlist, foreground, bounds, password metadata, stop file และ paused เหมือนเดิม ไม่มีการเปิดสิทธิ์รวมให้ AI ความเสี่ยง focus race และข้อจำกัด live acceptance ยังตาม DESKTOP-INPUT-TH.md

GUI นี้ทดสอบเฉพาะพิมพ์ข้อความสั้น ปุ่มหยุดตอบสนองระหว่างรอโฟกัสได้ แต่ native call ที่เริ่มแล้วไม่สามารถยกเลิกกลาง call ผ่าน GUI ได้ ยังมี guard ต่ออักขระสำหรับ Escape/stop file ไม่มีการรับรองว่าการพิมพ์ผ่านเท่ากับคลิก/ลากผ่าน
