สร้างสมาชิกใหม่ (admin เท่านั้น — token แสดงครั้งเดียว)

⏳ Token ใหม่ — คัดลอกเก็บทันที เปิดหน้านี้ครั้งต่อไปจะไม่แสดงอีก:
สร้างสำเร็จ → ระบบเก็บเฉพาะไฟล์ token ฝั่ง Node (data/roles/<ชื่อ>.token) — ตัวเลข token ไม่ถูกบันทึกในแชท/รายงานใด

กติกาโดยตั้ง (fail-closed)

เคสผล
ไม่มี token / token ไม่รู้จัก401 ทุก /api/* — ทำอะไรไม่ได้เลย
POST เส้นทางที่ไม่อยู่ตารางadmin เท่านั้น (403 สำหรับ operator/viewer)
viewer สั่งงาน/POST ใด ๆ403 — อ่านได้อย่างเดียว
operator รัน shell403 — คุมสูงสุด (ติดตั้ง/คำสั่งระบบ)
ธง roles_enabled = offพฤติกรรมเดิม 100% token เดียว = ทุกสิทธิ์
หน้านี้อ่านอย่างเดียวได้ทุก role — ปุ่มสร้างโชว์เฉพาะ admin (ธงปิด = ทุก token คือ admin)
